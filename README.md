# Text Utils (React)

A versatile React text manipulation and analysis utility built with TypeScript and Tailwind CSS.

## Features

- **Case Conversion:** Convert between UPPERCASE, lowercase, Title Case, camelCase, and kebab-case.
- **Whitespace Cleaner:** Remove redundant spaces, tabs, and trailing linebreaks.
- **Text Metrics:** Word count, character count, reading time estimate, and syllable analysis.

## Tech Stack

- React
- TypeScript
- Vite / Tailwind CSS

## Run Locally

```bash
npm install
npm run dev
```
